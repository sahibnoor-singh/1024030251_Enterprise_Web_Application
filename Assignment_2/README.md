## How to run

From inside each project's `src` folder:

```bash
# q1 - Food Delivery
cd FoodDeliverySystem/src
javac food/model/*.java food/service/*.java food/utility/*.java food/main/*.java
java food.main.Main

# q2 - lib system
cd LibrarySystem/src
javac library/model/*.java library/service/*.java library/util/*.java library/main/*.java
java library.main.Main
```

or u can just open it in intellij and run it directly.
